# Dana desktop

Downloads of the Dana desktop app for Windows and macOS. Get the newest one from
[Releases](https://github.com/zhssnym/dana-desktop/releases/latest).

The app is a window on [dana.so](https://dana.so) with a tray, start at login, quick add
(Ctrl+Shift+Space) and system notifications. It updates itself.

- **Windows:** run `Dana_…_x64-setup.exe`. SmartScreen asks once: click More info, then Run anyway.
- **macOS:** open `Dana_…_universal.dmg` and drag Dana to Applications. The first time, open
  System Settings > Privacy & Security and click Open Anyway.

This repository holds only the releases. Dana itself is developed elsewhere.
